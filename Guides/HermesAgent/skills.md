# Навыки для Hermes Agent

Официальные источники: [Creating Skills](https://hermes-agent.nousresearch.com/docs/developer-guide/creating-skills), [Skills System](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills).

## Путь и состав

В этом репозитории храни навыки в `Skills/HermesAgent/<имя>/`. В каталоге навыка должен быть `SKILL.md`; вспомогательные материалы размещай рядом, например:

```text
my-skill/
├── SKILL.md
├── references/
└── scripts/
```

В `SKILL.md` используй YAML frontmatter с обязательными для Hermes полями `name` и `description`. Добавляй `version`, `author`, `license`, `platforms` и секцию `metadata.hermes` только при необходимости. Для системных переменных и настроек пользуйся поддерживаемыми полями `required_environment_variables`, `required_credential_files` и `metadata.hermes.config`; секреты не клади в конфигурационные значения, репозиторий или текст навыка.

Пиши инструкцию как процедуру для агента: когда активировать навык, какие инструменты Hermes применять, как обрабатывать ошибки и как понять, что задача завершена. Учитывай, что доступность некоторых полей, скриптов и инструментов зависит от версии и среды Hermes.

## Установка и обнаружение

Для локальной разработки можно добавить в `~/.hermes/config.yaml` внешний каталог:

```yaml
skills:
  external_dirs:
    - /absolute/path/to/Agents-Skills/Skills/HermesAgent
```

Внешний каталог — не граница только для чтения: Hermes или агент могут изменять найденные там файлы. Если исходник должен быть защищён, настрой права файловой системы или работай с локальной копией. Изменения обычно подхватываются в новых сессиях.

Для обычной установки навык можно скопировать в `~/.hermes/skills/<имя>/` либо опубликовать в поддерживаемом источнике и установить средствами Hermes Skills. При публикации сохрани `SKILL.md` и все требуемые относительные файлы.

## Проверка

Если версия Hermes поддерживает эти команды, используй их перед распространением:

```bash
hermes skills list
```

Найди навык командой `/skills search <имя>` в сессии, затем вызови его slash-командой или дай обычный запрос, который должен его активировать. Убедись, что нужные ссылки и файлы действительно доступны.

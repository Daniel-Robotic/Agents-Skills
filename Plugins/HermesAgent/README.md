# Hermes Agent plugins

Пока здесь нет плагинов. Для нативного Hermes-плагина добавьте отдельную папку плагина с `plugin.yaml` и Python entry point (`register(ctx)`). Для переносимого Agent Plugins v1 пакета используйте его формат (`plugin.json`, `skills/`, опционально `mcp.json`). См. [официальное руководство](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins).

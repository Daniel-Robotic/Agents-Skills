# Lesson Studio для Hermes Agent

Набор из 12 навыков для подготовки планов и подробных занятий по математике, Python, ML, нейросетям, NLP, компьютерному зрению, AI-агентам, развёртыванию моделей, MLOps и DevOps. Пакет использует доступные Hermes инструменты для работы с материалами и поиска источников; отдельные ключи и сервисы ему не нужны.

## Установка

Скачайте репозиторий, если его ещё нет:

```bash
git clone https://github.com/Daniel-Robotic/Agents-Skills.git
cd Agents-Skills
```

Скопируйте **всю папку** `Plugins/HermesAgent/lesson-studio` в `~/.hermes/plugins/lesson-studio` и включите пакет:

```bash
hermes plugins enable lesson-studio
```

На Windows путь к плагинам обычно находится в `$HOME\.hermes\plugins\`. После включения начните новую сессию Hermes. При необходимости проверьте обнаружение командой `hermes plugins list`.

Этот пакет использует формат Portable Agent Plugins: в корне лежит `plugin.json`, а навыки находятся в `skills/`. Их не нужно по отдельности копировать в `~/.hermes/skills/`.

## Как пользоваться

Попросите Hermes: «Подготовь план занятия на тему градиентного спуска» или «Составь подробное занятие по классификации текстов». Общий навык `lesson-builder` уточнит количество практических работ и способ подбора дополнительных материалов. При необходимости он уточнит уровень группы и условия занятия. Предметный навык подключается по теме.

Результат содержит 3–5 целей, 3–5 блоков с общим таймингом ровно 90 минут и выводы, соответствующие целям. Каждая выбранная практическая работа рассчитана на 10–15 минут **сверх** 90 минут. Домашнее задание, рефлексия и ключ ответов добавляются только по запросу.

Если у вас уже есть материалы, приложите их к запросу и скажите, какие использовать. Если нужны новые ссылки, попросите найти их; навык должен проверить найденные страницы перед включением в занятие.

## Состав

`lesson-builder` отвечает за структуру и качество занятия. Предметные навыки: `math-foundations`, `python-programming`, `classical-ml`, `neural-networks-pytorch`, `natural-language-processing`, `classical-computer-vision`, `modern-computer-vision`, `ai-agents-harnesses`, `model-deployment`, `mlops`, `devops`.

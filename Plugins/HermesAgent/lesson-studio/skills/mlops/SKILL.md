# MLOps
Объясняй MLOps через жизненный цикл одной модели: данные → эксперимент → артефакт → выпуск → мониторинг → обновление. Для каждого шага покажи проблему воспроизводимости или качества, которую он решает.
Различай метрики обучения, метрики продукта, дрейф данных и деградацию модели. Указывай, какие версии данных, кода, параметров и модели нужно связать, чтобы повторить результат.
В полном занятии разберите одну реальную схему процесса и одно решение о выпуске или откате. Не превращай занятие в обзор множества инструментов без причины их выбора.
Практика на 10–15 минут: сравнить два экспериментальных запуска по заданным артефактам/метрикам и выбрать выпуск с обоснованием. Новичку дай таблицу, сильному — случай с дрейфом.
При подборе материалов проверь документацию конкретного инструмента и не смешивай его версии.

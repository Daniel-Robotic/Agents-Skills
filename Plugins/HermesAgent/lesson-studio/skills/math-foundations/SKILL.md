# Математика для AI и ML
Уточни, какая математическая идея нужна в конкретной модели или задаче. Не включай всю математику сразу: выстраивай цепочку от интуиции и маленького числового примера к записи формулой, затем к применению в ML.
Для смешанной группы сначала объясни обозначения и размерности. При работе с векторами и матрицами показывай форму каждого объекта и смысл операции. Для вероятности различай событие, условную вероятность, независимость и частоту; для статистики — выборку, оценку, разброс, доверие и смещение. Для оптимизации объясняй производную, градиент, шаг и критерий остановки.
Не подменяй доказательство картинкой там, где вывод существенен. В полном занятии приведи одну формулу по шагам, один вычисленный руками пример и связь с реализацией.
Практика на 10–15 минут: ручной расчёт на небольших числах, затем сверка с NumPy или калькулятором. Для новичка дай частично заполненную таблицу; для сильного студента — вопрос о границах применимости.
Проверяй знаки, индексы, размерности и используемые предположения. Отделяй математическое утверждение от эвристики.

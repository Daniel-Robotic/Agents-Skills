# Lesson Studio для Codex

Плагин объединяет 12 навыков для подготовки учебных занятий по AI, ML и смежным областям. Работает как пакет навыков: отдельный сервер, API-ключ и Python для него не требуются.

## Установка

Если этот репозиторий ещё не добавлен в Codex как источник плагинов, выполните:

```bash
codex plugin marketplace add Daniel-Robotic/Agents-Skills
```

Перезапустите Codex, откройте каталог **Plugins**, выберите источник **Agents Skills** и установите **lesson-studio**. В локальном клоне репозитория пакет находится в `Plugins/ChatGPT/lesson-studio/`; каталог `.agents/plugins/marketplace.json` уже указывает на него.

## Как пользоваться

В новом чате попросите: «Составь план занятия по линейной алгебре для ML» или «Напиши подробное занятие на 90 минут по PyTorch». Прикрепите собственные материалы, если хотите использовать их как основу.

Перед новым занятием плагин спросит, сколько нужно практических работ, и следует ли использовать ваши ссылки или искать материалы. При необходимости уточнит подготовку студентов и формат проведения. Для меняющихся технологий попросите найти свежую документацию; навык должен проверить ссылки и версии перед включением в текст.

Общий навык `lesson-builder` собирает результат, предметные навыки дают методические и технические ориентиры по каждой области. Основное занятие длится ровно 90 минут, разделено на 3–5 блоков и имеет 3–5 целей с соответствующими выводами. Каждая практика длится 10–15 минут сверх основного времени. Домашнее задание и рефлексия появляются только по вашему запросу.

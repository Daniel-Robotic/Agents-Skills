# Развёртывание моделей
Начни с требования: где работает модель, сколько запросов, допустимая задержка, память, стоимость и доступность. Различай сохранение артефакта, загрузку, инференс, API и эксплуатацию сервиса.
В полном занятии покажи минимальный путь от обученной/готовой модели до одного воспроизводимого запроса и ответа. Объясни версии модели и зависимостей, форму входа/выхода, обработку ошибок и простые измерения задержки.
Сравнивай CPU/GPU, батчинг, квантование и кэширование только когда они нужны для задачи. Не обещай конкретную скорость без измерения на указанном оборудовании.
Практика на 10–15 минут: запустить готовую модель как локальный endpoint или разобрать готовый пример, сделать запрос и проверить формат ответа. Новичку дай готовый сервис; сильному — измерить latency.
Для меняющихся фреймворков и сервисов сверяй актуальные команды и версии в официальных документах.

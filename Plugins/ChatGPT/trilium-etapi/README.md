# Trilium ETAPI для Codex Desktop

Плагин позволяет Codex читать и изменять заметки Trilium через официальный REST API. Codex запускает входящий в пакет Python-клиент на вашем компьютере; запросы уходят напрямую на ваш сервер Trilium.

## Что понадобится

- Codex Desktop с поддержкой локальных плагинов.
- Python 3, доступный командой `python`.
- Публичный HTTPS-адрес Trilium, например `https://notes.example.com`.
- ETAPI-ключ из **Trilium → Options → ETAPI**.

Этот пакет рассчитан на Codex Desktop: навыку нужен локальный запуск Python. В браузерном чате ChatGPT такой запуск недоступен.

## Установка

Добавьте GitHub-репозиторий как источник плагинов:

```bash
codex plugin marketplace add Daniel-Robotic/Agents-Skills
```

Перезапустите Codex Desktop. Откройте каталог **Plugins**, выберите источник **Agents Skills** и установите **trilium-etapi**. Путь к плагину уже задан в каталоге репозитория `.agents/plugins/marketplace.json`; копировать отдельные файлы вручную не требуется.

## Настройка Trilium

На компьютере, где работает Codex Desktop, задайте две переменные окружения:

| Переменная | Значение |
| --- | --- |
| `TRILIUM_BASE_URL` | Адрес Trilium без `/etapi`, например `https://notes.example.com` |
| `TRILIUM_ETAPI_TOKEN` | Ключ, созданный в **Trilium → Options → ETAPI** |

**Windows:** откройте «Изменение переменных среды текущего пользователя», создайте обе переменные в разделе пользовательских переменных и перезапустите Codex Desktop.

**Linux и macOS:** задайте переменные в окружении, из которого запускается Codex Desktop, и перезапустите приложение. Например, для текущей сессии терминала:

```bash
export TRILIUM_BASE_URL='https://notes.example.com'
export TRILIUM_ETAPI_TOKEN='ваш-ключ'
```

Ключ храните вне репозитория. Не добавляйте его в `plugin.json`, навык или чат. Если Codex не видит переменные, убедитесь, что они заданы именно для процесса приложения, а затем полностью перезапустите его.

## Использование

Откройте новый чат Codex и попросите: «Используй плагин Trilium: найди заметки о проекте и покажи краткое содержание». Для изменений можно попросить: «Создай заметку “План” внутри заметки “Проект”».

Навык вызывает локальный клиент `scripts/etapi.py`. Он поддерживает 42 операции официальной схемы ETAPI, включая заметки, дерево, вложения, историю, календарь, импорт и экспорт. Для передачи файлов клиент использует пути к локальным файлам.

Если запрос не проходит, сначала проверьте, что `python` доступен, обе переменные окружения заданы, а адрес Trilium открывается с этого компьютера. Для просмотра доступных операций внутри папки плагина можно выполнить:

```bash
python scripts/etapi.py list
```
